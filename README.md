# Big File Explorer

A GUI tool for exploring and working with `.BIG` / `.BIX` archives used by the **Sleeping Dogs** game.

It can browse and extract files from a range of Sleeping Dogs builds, including early prototypes, the original game, Sleeping Dogs: Definitive Edition, and Triad Wars.

Big File Explorer can also create new `.BIG` archives, but **packing is currently supported only for the Sleeping Dogs: Definitive Edition archive format**.

## Preview

![Program preview](images/preview.jpg)

## Features

- Browse `.BIG` / `.BIX` archives
- Extract files and folders
- View archive contents and file sizes
- Create new `.BIG` archives
- Add files and folders to archives

## Compatibility

| Game / Build | Browse | Extract | Pack |
|---|:---:|:---:|:---:|
| Early Sleeping Dogs prototypes | ✅ | ✅ | ❌ |
| Sleeping Dogs | ✅ | ✅ | ❌ |
| Sleeping Dogs: Definitive Edition | ✅ | ✅ | ✅ |
| Triad Wars | ✅ | ✅ | ❓ |

> Packing support is currently limited to the **Sleeping Dogs: Definitive Edition** archive format.

Compatibility may vary between individual builds and archives.
